# Студи / агентлагийн сайт

Вэб хөгжүүлэлтийн үйлчилгээ танилцуулах нэг хуудас сайт. Хар дэвсгэр, ягаан-улбар шар градиент, том Oswald гарчигтай.

## Хэсгүүд
Толгой цэс (дүрстэй тайлбартай Үйлчилгээ цэс) · Hero · Үйлчилгээ (6 карт) · Хамтран ажиллах 6 алхам · AI-ийн тухай · Студийн тухай · Түгээмэл асуулт · Портфолио · Үнийн багц · Үнийн тооцоолуур + хүсэлтийн форм · Footer

## Өөрийнхөөрөө болгох
- `index.html` — «Таны студи» гэсэн нэр, имэйл, утас, хаяг, портфолиогийн төслүүдийг солино.
  Портфолиогийн `.thumb` дотор `<img src="images/proj1.jpg" alt="">` тавьж болно.
- Лого — `index.html`-ийн эхэнд байгаа `<symbol id="mark">` SVG-г солих эсвэл `<img>` болгоно.
- Үнэ — тооцоолуурын `option value`, `data-price` утгууд (төгрөгөөр).
- Өнгө — `style.css`-ийн `:root` доторх `--pink`, `--orange`.
- `send.php` — `$TO` хувьсагчид формын хүсэлт хүлээн авах имэйлээ бичнэ.

## cPanel дээр тавих
`studio/` хавтсын доторх файлуудыг `public_html` (эсвэл дэд домэйны хавтас) руу хуулахад л болно. PHP-ийн `mail()` ажилладаг хостинг дээр форм имэйл илгээнэ. Өгөгдлийн сан шаардлагагүй.
