# Компанийн вэбсайт (уул уурхай / зам барилгын загвар)

altainzam.mn сайтын бүтэц, дизайнтай ижил компанийн танилцуулга сайт, админ панелтай. PHP 7.4+ ба MySQL/MariaDB-тэй ямар ч хостинг (cPanel) дээр ажиллана.

## Хуудсууд
- `index.php` — нүүр: бүтэн дэлгэцийн слайдер (Алсын хараа, Эрхэм зорилго, Үнэт зүйлс), шар дэвсгэртэй 3 үйл ажиллагаа, Бидний тухай, танилцуулга бичлэг
- `about.php`, `operations.php`, `news.php` (Мэдээ / Тайлан / Худалдан авалт дэд цэс), `careers.php`, `contact.php`
- Бүх хуудасны доор: сайтын бүтэц, холбоо барих, хаяг, **санал хүсэлтийн форм** (`send.php` и-мэйлээр илгээнэ)

## Суулгах
1. `company-site` доторх бүх файлыг `public_html` руу хуулна.
2. cPanel → **MySQL Databases** хэсгээс өгөгдлийн сан, хэрэглэгч үүсгээд хэрэглэгчийг сан руу **ALL PRIVILEGES** эрхтэй нэмнэ.
3. Хөтчөөр `таны-домэйн/install.php` руу орж өгөгдлийн сангийн нэр, хэрэглэгч, нууц үг болон админы нэвтрэх нэр, нууц үгээ оруулаад **Суулгах** дарна. Хүснэгтүүд автоматаар үүсч, анхны агуулгаар дүүрнэ, `config.php` үүснэ.
4. Суулгалт дууссаны дараа `install.php` дахин ажиллахгүй (админ руу шилжүүлнэ).

## Админ панел (`/admin`)
Админаас хийх боломжтой:
- **Слайдер, Үйл ажиллагаа, Мэдээ, Тайлан / худалдан авалт, Ажлын байр** — нэмэх, засах, устгах, дээш/доош зөөж эрэмбэлэх, зураг/файл хуулах
- **Нүүр хуудас** — "Бидний тухай" текст, зураг, танилцуулга бичлэг (YouTube холбоос эсвэл MP4 файл)
- **Бидний тухай** — танилцуулга, алсын хараа, эрхэм зорилго, үнэт зүйлс
- **Хүний нөөцийн бодлого**
- **Ерөнхий тохиргоо** — компанийн нэр, лого, утас, и-мэйл, хаяг, Facebook
- **Санал хүсэлт** — сайтаас ирсэн санал хүсэлтийг унших, устгах
- **Нууц үг солих**

Агуулга MySQL өгөгдлийн санд (`cs_` угтвартай хүснэгтүүд), хуулсан зураг/файл `uploads/` хавтсанд хадгалагдана. `uploads/` хавтсанд бичих эрх (755) байх ёстой. Нөөц хуулбар авахдаа phpMyAdmin → Export-оор өгөгдлийн сангаа, мөн `uploads/` хавтсаа хуулж авна.

| Хүснэгт | Агуулга |
|---|---|
| `cs_settings` | Ерөнхий тохиргоо, нүүр/бидний тухай/хүний нөөц хуудсын текст |
| `cs_slides`, `cs_services`, `cs_news`, `cs_docs`, `cs_jobs` | Слайд, үйл ажиллагаа, мэдээ, тайлан, ажлын байр |
| `cs_messages` | Санал хүсэлт |
| `cs_admins` | Админ хэрэглэгч (нууц үг шифрлэгдсэн) |
| `cs_login_attempts` | Буруу нэвтрэлтийн хязгаар |

Нууц үгээ мартвал phpMyAdmin-аас `cs_admins` хүснэгтийн мөрийг устгаад `install.php` руу орж админаа шинээр үүсгэнэ.

**Лого:** `assets/img/logo.png` (тэмдэг), `assets/img/logo-wordmark.png` (бичиг) — анхны өнгөөрөө, цагаан толгой хэсэгт дэвсгэргүй харагдана. Админ → Ерөнхий тохиргоо хэсгээс сольж болно.

Өнгө солих бол `assets/css/style.css` эхний `--yellow` хувьсагчийг өөрчилнө.

Локал дээр үзэх: MySQL ажиллуулаад энэ хавтсан дотроос `php -S localhost:8000`, дараа нь `http://localhost:8000/install.php`.
