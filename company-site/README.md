# Компанийн вэбсайт (уул уурхай / зам барилгын загвар)

altainzam.mn сайтын бүтэц, дизайнтай ижил компанийн танилцуулга сайт. PHP 7.4+ ажилладаг ямар ч хостинг (cPanel) дээр шууд ажиллана, өгөгдлийн сан шаардлагагүй.

## Хуудсууд
- `index.php` — нүүр: бүтэн дэлгэцийн слайдер (Алсын хараа, Эрхэм зорилго, Үнэт зүйлс), шар дэвсгэртэй 3 үйл ажиллагаа, Бидний тухай, танилцуулга бичлэг
- `about.php`, `operations.php`, `news.php` (Мэдээ / Тайлан / Худалдан авалт дэд цэс), `careers.php`, `contact.php`
- Бүх хуудасны доор: сайтын бүтэц, холбоо барих, хаяг, **санал хүсэлтийн форм** (`send.php` и-мэйлээр илгээнэ)

## Өөрийн болгох
1. **`config.php`** — компанийн нэр, лого дээрх бичиг, утас, и-мэйл, хаяг, Facebook, санал хүсэлт хүлээн авах и-мэйл.
2. **Зураг** — `assets/img/` доторх `.svg` зургууд түр зураг. Өөрийн жинхэнэ зургаа (`.jpg`) хуулаад `index.php`, бусад хуудсанд замыг нь солино. Лого: `assets/img/logo.svg`.
3. **Бичлэг** — `assets/video/intro.mp4` нэртэй тавибал нүүр хуудсанд автоматаар тоглуулагч гарна.
4. **Текст** — слайд, үйл ажиллагааны текстүүд `index.php` файлын дээд хэсгийн массивт байна.
5. **Өнгө** — `assets/css/style.css` эхний `--yellow` хувьсагч.

## Хостинг дээр тавих
`company-site` хавтасны доторх бүх файлыг `public_html` руу хуулна.

Локал дээр үзэх: `php -S localhost:8000` (энэ хавтсан дотроос).
